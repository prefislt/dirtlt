# dirtlt

dirt.lt svetainė

## Deployment

Auto-deployed to <https://prefislt.github.io/dirtlt/> on every push to `main`
via GitHub Actions (`.github/workflows/deploy.yml`).

- `npm run dev` — local dev server
- `npm run build` — production build into `dist/`
- Site base path is `/dirtlt/` (set in `vite.config.js`) — don't change it.
